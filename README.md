# 元素モンスターズ図鑑

## 1. サービス概要

元素記号ごとに連想される、キャラクターやモンスターなどのイメージ画像を投稿・閲覧できる、元素学習SNSサービス。<br>
元素とイメージ画像の情報を関連付けて、楽しみながら元素記号や性質を覚えられる。また、元素記号という切り口から、イラストを描いたり、AI生成で画像を作るクリエイターが、自分の作品をアウトプットする機会を提供する。

元素記号を暗記で覚えるのが大変と感じている学生や、イラストやキャラクター画像を見るのが好きな人、イラストを描くクリエイター向け。
元素記号や元素名は苦しい暗記学習になりやすく、覚えにくい。また、元素をモチーフにしたイラストをまとめてみられるサービスは少ない。
そこで、イメージ画像と元素を関連付けることで記憶しやすくし、さらに投稿・閲覧・お気に入りできるサービスとして提供する。

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

学生時代、元素記号を勉強したとき、「20個程度でも元素を暗記するのは大変だった」という記憶が今でも残っている。
一方で、子どもの頃に夢中になっていたポケモンは、151匹もの名前や特徴を自然と覚えていた。覚えようと意識したわけではなく、ゲームやアニメ、イラストを通して楽しみながら触れていた結果、気付けば記憶に定着していた。

この経験から、「もし元素もポケモンのように、それぞれが個性的なキャラクターやモンスターとして表現されていたら、もっと楽しく学べるのではないか」と考えるようになった。

また、私はSNS等でイラストを見ることが好きで、多くのクリエイターの発想力や表現力にいつも驚かされている。さらに近年は生成AIの普及により、誰でも自分のアイデアをイラストとして形にしやすい時代になった。

例えば、「H(水素)だから水属性魔法を使う小さな少年にしよう」「Au(金)だから金の鎧を着た騎士にしよう」といった小さな発想でも、それをイラストとして共有することで、誰かが元素を覚えるきっかけになるかもしれない。

クリエイターの小さなアイデアが、子どもたちや学習者の「覚えやすい」「楽しい」を生み出し、その積み重ねが未来の科学者を育てるきっかけになるかもしれない。

そんな「学び」と「創作」がつながる場所があったら面白いと思い、このサービスを考えるようになった。

### 2-2. なぜそれが「気になった」のか

人は文字だけよりも、イラストやイメージ等と関連付けた方が記憶に残りやすい。認知心理学では「絵優位性効果」や「二重符号化理論」として研究されており、文字情報に加えて、視覚情報を組み合わせることで、記憶の定着を助けることが示されている。

一方で、元素をテーマにしたキャラクター作品はいくつか存在するものの、クリエイターが自分でデザインした元素キャラクターを投稿・共有したり、自分のお気に入りの元素キャラクターを図鑑のように登録・コレクションしたりできるサービスや場所は見つからなかった。

そのため、「無ければ自分で作ってしまおう」と考えた。

#### 参考文献
  - 二重符号化理論：Paivio, A. (1971). Imagery and Verbal Processes.
  - 絵優位性効果：Standing, L. (1973). Learning 10,000 Pictures.
